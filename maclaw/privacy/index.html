McNav Privacy Policy

Last updated: June 1, 2026

McNav is designed to run primarily on your Mac. It does not operate an AllNew-hosted backend for app data, does not include advertising SDKs, and does not sell or share user data for tracking.

Best-effort security notice: Privacy Filter, URL content guards, and Secret Broker reduce risk, but they do not guarantee complete detection, complete anonymization, or prevention of every disclosure. Review sensitive actions before approving them.

Data Used to Track You

None. McNav does not track you across apps or websites.

Data Linked to You

None collected by AllNew. StoreKit purchases are processed by Apple. McNav receives Apple-signed entitlement information, not a customer profile controlled by AllNew.

Secret Broker

Secret Broker lets users store API keys, bank details, passwords, or other secret strings locally in macOS Keychain. MCP tools never return the raw secret value. They return only non-secret metadata such as an ID, kind, display name, tags, byte count, timestamps, and a local verification code derived with a local Keychain key.

Display names and tags may be visible to the AI client, so users should not put the secret value itself into those fields. When the user approves a paste operation, McNav may place the value on the system clipboard briefly and then attempt to clear it. During that short window, other local apps may be able to read the clipboard.

URL and Web Content Risk

Web pages, browser snapshots, clipboard text, and files can contain malicious instructions aimed at AI agents. McNav marks external content as untrusted, wraps it with a content-boundary notice, blocks high-confidence indirect prompt-injection and exfiltration patterns, and requires confirmation for suspicious URL forms such as embedded credentials, IP literals, URL shorteners, Punycode lookalikes, and nested redirect parameters.

Permissions

McNav uses macOS permission prompts for Calendar, Reminders, Contacts, Screen Recording, Accessibility, Notifications, and user-selected folders only when the related tool or feature is used. Users can revoke permissions at any time in System Settings.
