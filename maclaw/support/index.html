FAQ

What is McNav?

McNav is a macOS app and bundled MCP helper that lets AI assistants use public macOS APIs through a controlled, audited surface. It is designed for Claude Desktop, Codex Desktop, and other MCP-compatible clients.

Does McNav require an account?

No AllNew account is required. Paid access, subscriptions, trials, restores, and offer-code redemption are handled by Apple StoreKit.

How do I set it up?

Open McNav, review the dashboard, grant only the macOS permissions you need, and copy the Claude Desktop or Codex Desktop MCP setup snippet from the app. For workspace access, grant only folders you want AI-assisted workflows to use.

How does McNav protect secrets?

Secret Broker stores secret values in macOS Keychain and returns only metadata and local verification codes to MCP clients. Pasting a secret requires confirmation and uses the system clipboard briefly, so users should still be careful around other local apps.

What about malicious web pages or URLs?

McNav treats crawled URL content, browser snapshots, clipboard text, and files as untrusted external content. It adds data-boundary notices, blocks high-confidence indirect prompt-injection and exfiltration patterns, and asks for confirmation on suspicious URL forms.

How can I cancel or restore purchases?

Use the Subscription tab in McNav to restore purchases or open Apple's subscription management. Cancellation, refunds, final pricing, taxes, and renewal terms are controlled by Apple and shown in the App Store purchase sheet.

App Review Notes

McNav does not download executable code, does not include a privileged helper, does not use custom external payment unlocks, and does not require Full Disk Access. The bundled mcnav-mcpd helper is fixed at ship time inside the app bundle and is spawned over stdio by MCP-compatible clients.
