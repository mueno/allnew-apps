McNavとは何ですか？+

McNavは、Claude Desktop、Codex Desktop、その他のMCP互換クライアントが、macOSの公開APIをユーザー管理の監査済み経路で利用できるようにするmacOSアプリと同梱mcnav-mcpd MCPヘルパーです。

アカウントは必要ですか？+

AllNewアカウントは不要です。有料アクセス、サブスクリプション、無料体験、購入復元、offer code redemptionはApple StoreKitで管理されます。

どう設定しますか？+

McNavを開き、必要なmacOS権限だけを許可し、アプリ内のClaude DesktopまたはCodex Desktop用MCP設定スニペットをコピーしてください。ワークスペースアクセスは、AI支援ワークフローで使いたいフォルダだけを許可してください。

秘密情報はどのように保護されますか？+

Secret Brokerは秘密値をmacOS Keychainに保存し、MCPクライアントにはメタデータとローカル確認コードだけを返します。貼り付けには確認が必要で、システムクリップボードを短時間だけ使用します。

悪意あるWebページやURLへの対策は？+

McNavはクロールされたURL内容、ブラウザスナップショット、クリップボード、ファイルを信頼できない外部コンテンツとして扱い、境界表示、間接プロンプトインジェクション検出、疑わしいURL形式での確認を行います。

購入をキャンセルまたは復元するには？+

McNavのSubscriptionタブから購入復元やAppleのサブスクリプション管理を開けます。解約、返金、最終価格、税、更新条件はAppleが管理し、App Store購入画面に表示されます。

5. Secret Broker

Secret Brokerは、APIキー、銀行情報、パスワード、その他の秘密文字列をmacOS Keychainにローカル保存します。MCPツールは秘密値そのものを返さず、ID、種類、表示名、タグ、バイト数、タイムスタンプ、ローカルKeychainキーから派生した確認コードなど、非秘密のメタデータのみを返します。

表示名やタグはAIクライアントに見える場合があるため、秘密値そのものを入力しないでください。ユーザーが貼り付け操作を承認した場合、McNavは短時間だけ値をシステムクリップボードに置き、その後クリアを試みます。その短い間、他のローカルアプリがクリップボードを読み取れる可能性があります。

6. 安全化・最小化

Privacy Filterは既定で有効になり、送信前に個人情報や秘密値の可能性がある内容を検出・マスキングするよう試みます。監査ログは、ツール引数やPIIを含む可能性があるフィールドについて、生データではなくSHA-256ハッシュや要約情報を記録する設計です。ユーザーは監査ログをローカルで確認、削除、または手動エクスポートできます。

ただし、Privacy Filter、URL content guards、Secret Brokerはリスクを低減するベストエフォート機能であり、完全な検出、完全な匿名化、またはすべての開示防止を保証するものではありません。機密性の高い操作を承認する前に内容を確認してください。

7. URLおよびWebコンテンツのリスク

Webページ、ブラウザスナップショット、クリップボード文字列、ファイルには、AIエージェントを狙った悪意ある指示が含まれる場合があります。McNavは外部コンテンツを信頼できないものとして扱い、境界表示を付け、高信頼度の間接プロンプトインジェクションや外部送信パターンをブロックし、埋め込み認証情報、IPリテラル、短縮URL、Punycode類似ドメイン、ネストしたリダイレクトパラメータなどの疑わしいURL形式では確認を求めます。

Frequently Asked Questions
Answers about setup, safety, and purchases
What is McNav?+

McNav is a macOS app and bundled mcnav-mcpd MCP helper that lets Claude Desktop, Codex Desktop, and other MCP-compatible clients use public macOS APIs through a controlled, audited surface.

Does McNav require an account?+

No AllNew account is required. Paid access, subscriptions, trials, restores, and offer-code redemption are handled by Apple StoreKit.

How do I set it up?+

Open McNav, grant only the macOS permissions you need, and copy the Claude Desktop or Codex Desktop MCP setup snippet from the app. For workspace access, grant only folders you want AI-assisted workflows to use.

How does McNav protect secrets?+

Secret Broker stores secret values in macOS Keychain and returns only metadata and local verification codes to MCP clients. Pasting a secret requires confirmation and uses the system clipboard briefly.

What about malicious web pages or URLs?+

McNav treats crawled URL content, browser snapshots, clipboard text, and files as untrusted external content. It adds data-boundary notices, blocks high-confidence indirect prompt-injection and exfiltration patterns, and asks for confirmation on suspicious URL forms.

How can I cancel or restore purchases?+

Use the Subscription tab in McNav to restore purchases or open Apple's subscription management. Cancellation, refunds, final pricing, taxes, and renewal terms are controlled by Apple and shown in the App Store purchase sheet.

5. Secret Broker

Secret Broker lets users store API keys, bank details, passwords, or other secret strings locally in macOS Keychain. MCP tools never return the raw secret value. They return only non-secret metadata such as an ID, kind, display name, tags, byte count, timestamps, and a local verification code derived with a local Keychain key.

Display names and tags may be visible to the AI client, so users should not put the secret value itself into those fields. When the user approves a paste operation, McNav may place the value on the system clipboard briefly and then attempt to clear it. During that short window, other local apps may be able to read the clipboard.

6. Safety and Minimization

Privacy Filter is enabled by default and attempts to detect and mask likely personal information or secret values before transmission. Audit logs are designed to store SHA-256 hashes or summary information instead of raw tool arguments or fields that may contain PII. Users can review, delete, or manually export audit logs locally.

Privacy Filter, URL content guards, and Secret Broker are best-effort controls that reduce risk, but they do not guarantee complete detection, complete anonymization, or prevention of every disclosure. Review sensitive actions before approving them.

7. URL and Web Content Risk

Web pages, browser snapshots, clipboard text, and files can contain malicious instructions aimed at AI agents. McNav marks external content as untrusted, wraps it with a content-boundary notice, blocks high-confidence indirect prompt-injection and exfiltration patterns, and requires confirmation for suspicious URL forms such as embedded credentials, IP literals, URL shorteners, Punycode lookalikes, and nested redirect parameters.
